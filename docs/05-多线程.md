# 05 — C++ 多线程与并发编程

## 1. 核心概念

C++11 起，标准库提供了完整的并发支持，告别平台特定的 pthread/Windows Thread API。

核心组件：
- `std::thread` — 线程对象
- `std::mutex` + `std::lock_guard` — 互斥锁
- `std::condition_variable` — 条件变量（等待/通知）
- `std::async` + `std::future` — 异步任务
- `std::atomic` — 无锁原子操作

**为什么用标准库多线程？**跨平台、类型安全、RAII自动管理资源、与STL深度集成。

## 2. 快速上手

```cpp
#include <iostream>
#include <thread>
#include <mutex>
#include <vector>

std::mutex cout_mutex;  // 保护 std::cout

void worker(int id) {
    std::lock_guard<std::mutex> lock(cout_mutex);
    std::cout << "线程 " << id << " 正在工作\n";
}

int main() {
    std::vector<std::thread> threads;
    for (int i = 0; i < 4; ++i) {
        threads.emplace_back(worker, i);  // 创建线程
    }
    for (auto& t : threads) {
        t.join();  // 等待所有线程结束
    }
    std::cout << "所有线程完成\n";
    return 0;
}
```

## 3. 常用API / 写法速查

### 3.1 std::thread

```cpp
#include <thread>

// 创建线程
std::thread t1([] { std::cout << "lambda线程\n"; });
std::thread t2(worker, arg1, arg2);  // 传参

// 分离 / 等待
t1.join();    // 主线程等待 t1 结束
t2.detach();  // t2 独立运行，不再可控（慎用）

// 获取硬件并发数
unsigned int n = std::thread::hardware_concurrency();
```

### 3.2 std::mutex / lock_guard / unique_lock

```cpp
#include <mutex>

std::mutex mtx;
int shared_counter = 0;

void safe_increment() {
    // lock_guard：RAII，构造时加锁，析构时解锁
    std::lock_guard<std::mutex> lock(mtx);
    ++shared_counter;
}

void conditional_increment(bool should_inc) {
    // unique_lock：可手动 lock / unlock，可与条件变量配合
    std::unique_lock<std::mutex> lock(mtx);
    if (should_inc) ++shared_counter;
    lock.unlock();   // 手动提前解锁
    // ... 做一些无需锁的事 ...
}

// 同时锁多个互斥体（避免死锁）
std::mutex a, b;
{
    std::scoped_lock lock(a, b);  // C++17 推荐，自动避免死锁
    // 同时持有 a 和 b
}
```

### 3.3 std::condition_variable

```cpp
#include <condition_variable>
#include <queue>

std::mutex mtx;
std::condition_variable cv;
std::queue<int> data_queue;
bool done = false;

// 生产者
void producer() {
    for (int i = 0; i < 10; ++i) {
        {
            std::lock_guard lock(mtx);
            data_queue.push(i);
        }
        cv.notify_one();  // 通知一个等待的消费者
    }
    {
        std::lock_guard lock(mtx);
        done = true;
    }
    cv.notify_all();
}

// 消费者
void consumer() {
    while (true) {
        std::unique_lock lock(mtx);
        cv.wait(lock, [] { return !data_queue.empty() || done; });
        // wait 等价于：while(!条件) { cv.wait(lock); }

        if (!data_queue.empty()) {
            int val = data_queue.front();
            data_queue.pop();
            lock.unlock();  // 处理数据前释放锁
            std::cout << "消费: " << val << "\n";
        } else if (done) {
            break;
        }
    }
}
```

### 3.4 std::async / future / promise

```cpp
#include <future>

// async：异步执行，返回 future
int heavy_compute(int n) {
    int sum = 0;
    for (int i = 0; i < n; ++i) sum += i;
    return sum;
}

auto fut = std::async(std::launch::async, heavy_compute, 1000000);
// 主线程可以做其他事...
int result = fut.get();  // 阻塞直到结果就绪

// promise / future 配对：手动设置结果
std::promise<std::string> prom;
std::future<std::string> fut2 = prom.get_future();

std::thread([&prom] {
    prom.set_value("计算完成");  // 设置结果
}).detach();

std::cout << fut2.get() << "\n";  // 获取结果

// shared_future：多次获取
std::shared_future<int> shared = fut.share();
auto val1 = shared.get();  // OK
auto val2 = shared.get();  // OK（shared_future 可多次 get）
```

### 3.5 std::atomic

```cpp
#include <atomic>

std::atomic<int> counter{0};
std::atomic<bool> flag{false};

void increment() {
    for (int i = 0; i < 1000; ++i) {
        counter.fetch_add(1, std::memory_order_relaxed);
        // 等价于 ++counter，但默认 memory_order_seq_cst
    }
}

// 无锁的开关
void worker() {
    while (!flag.load(std::memory_order_acquire)) {
        // 自旋等待
    }
    // flag 已为 true
}
```

### 3.6 线程池模式

```cpp
#include <thread>
#include <vector>
#include <queue>
#include <functional>
#include <future>
#include <type_traits>

class ThreadPool {
public:
    explicit ThreadPool(size_t num_threads) {
        for (size_t i = 0; i < num_threads; ++i) {
            workers_.emplace_back([this] {
                while (true) {
                    std::function<void()> task;
                    {
                        std::unique_lock lock(queue_mutex_);
                        cv_.wait(lock, [this] { return stop_ || !tasks_.empty(); });
                        if (stop_ && tasks_.empty()) return;
                        task = std::move(tasks_.front());
                        tasks_.pop();
                    }
                    task();
                }
            });
        }
    }

    // 提交任务，返回 future
    template<typename F, typename... Args>
    auto enqueue(F&& f, Args&&... args)
        -> std::future<std::invoke_result_t<F, Args...>>
    {
        using return_type = std::invoke_result_t<F, Args...>;
        auto task = std::make_shared<std::packaged_task<return_type()>>(
            std::bind(std::forward<F>(f), std::forward<Args>(args)...)
        );
        std::future<return_type> res = task->get_future();
        {
            std::lock_guard lock(queue_mutex_);
            if (stop_) throw std::runtime_error("线程池已停止");
            tasks_.emplace([task] { (*task)(); });
        }
        cv_.notify_one();
        return res;
    }

    ~ThreadPool() {
        {
            std::lock_guard lock(queue_mutex_);
            stop_ = true;
        }
        cv_.notify_all();
        for (auto& worker : workers_) {
            if (worker.joinable()) worker.join();
        }
    }

private:
    std::vector<std::thread> workers_;
    std::queue<std::function<void()>> tasks_;
    std::mutex queue_mutex_;
    std::condition_variable cv_;
    bool stop_ = false;
};
```

## 4. 常见陷阱 & 最佳实践

| 陷阱 | 说明 | 正确做法 |
|------|------|----------|
| **数据竞争** | 多线程读写同一变量无保护 | 用 mutex 或 atomic |
| **死锁** | 多个锁交叉等待 | 固定加锁顺序，或用 `std::lock` / `scoped_lock` |
| **忘记 join/detach** | thread 析构时仍 joinable → `std::terminate` | 确保线程结束前调用 join 或 detach |
| **锁粒度过大** | 持有锁期间做耗时操作，性能低下 | 锁内只操作共享数据，处理后尽快释放 |
| **条件变量虚假唤醒** | `cv.wait()` 可能无故返回 | 始终用带谓词的 `cv.wait(lock, predicate)` |
| **future 未获取** | async 返回的 future 析构会阻塞 | 保存 future 或在合适时机 get |
| **atomic 非万能** | 多个 atomic 操作不构成原子整体 | 复杂操作用 mutex |

**最佳实践：**

- 优先用 `std::scoped_lock`（C++17）替代 `std::lock_guard`
- 用 `std::async` 做简单的并行任务，用线程池做大规模任务
- 条件变量 always 用带谓词的重载：`cv.wait(lock, []{ return ready; })`
- 共享数据尽量封装在一个类中，通过成员函数加锁访问
- 能用 `atomic` 就不用 `mutex`，能用 `mutex` 就不设计复杂并发逻辑

## 5. 生产项目典型用法

### 场景：并行文件下载器

```cpp
#include <thread>
#include <vector>
#include <queue>
#include <mutex>
#include <condition_variable>
#include <functional>
#include <future>
#include <atomic>

// 使用上一节的 ThreadPool
class ParallelDownloader {
public:
    ParallelDownloader(size_t threads) : pool_(threads) {}

    // 提交下载任务（模拟）
    std::future<bool> download(const std::string& url, const std::string& save_path) {
        return pool_.enqueue([this, url, save_path] {
            std::this_thread::sleep_for(std::chrono::milliseconds(500)); // 模拟IO
            // 实际应调用 libcurl 或系统API下载文件
            return true;
        });
    }

    // 批量下载
    std::vector<std::future<bool>> download_all(
        const std::vector<std::pair<std::string, std::string>>& tasks)
    {
        std::vector<std::future<bool>> futures;
        for (const auto& [url, path] : tasks) {
            futures.push_back(download(url, path));
        }
        return futures;
    }

private:
    ThreadPool pool_;
};

int main() {
    ParallelDownloader downloader(4);

    std::vector<std::pair<std::string, std::string>> tasks = {
        {"http://example.com/a.zip", "a.zip"},
        {"http://example.com/b.zip", "b.zip"},
        {"http://example.com/c.zip", "c.zip"},
    };

    auto futures = downloader.download_all(tasks);

    int success = 0;
    for (auto& fut : futures) {
        if (fut.get()) ++success;
    }
    std::cout << "下载完成: " << success << "/" << tasks.size() << "\n";
    return 0;
}
```
