# C++ 核心技能速成指南

> 面向有编程基础（LeetCode 500题），需在数天内快速上手C++工程开发的开发者。

## 学习路径总览

| 优先级 | 模块 | 核心概念 | 预计时间 |
|--------|------|---------|---------|
| 🔴 P0 | **STL** | 容器/算法/迭代器/智能指针 | 4h |
| 🔴 P0 | **CMake** | 项目构建/依赖管理 | 3h |
| 🔴 P0 | **Git** | 分支/合并/协作流程 | 2h |
| 🟡 P1 | **JSON** | 序列化/反序列化 | 1h |
| 🟡 P1 | **多线程** | thread/mutex/async | 3h |
| 🟡 P1 | **SQLite** | CRUD/事务 | 2h |
| 🟡 P1 | **动态库/插件** | DLL/显式加载 | 2h |
| 🟢 P2 | **libcurl** | HTTP请求/REST API | 2h |
| 🟢 P2 | **Qt** | 信号槽/Widget/布局 | 6h |
| 🟢 P2 | **OpenCV** | 图像处理/OCR | 4h |
| 🟢 P2 | **ONNX Runtime** | 模型推理 | 3h |

## 环境要求

- **编译器**: GCC 7+ / MSVC 2019+ / Clang 10+
- **构建系统**: CMake 3.16+
- **系统**: Windows / Linux / macOS

## 配套项目

本目录下的 `LearningAssistant/` 是一个综合教学应用，涵盖以上所有模块。
每个模块在 `examples/` 下有独立可运行的示例代码。
